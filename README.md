# 學測國文閱讀作答研究｜線上施測系統

本系統用於國科會大專生計畫「從認知負荷探討AI模擬作答與人類實際測驗表現落差：以學科能力測驗為例」，由**受試者版**與**管理者版**兩個網頁組成。題目、頁面文字與作答資料都存在研究者的 Google 試算表，本網站與 GitHub 上沒有任何作答資料。

| 系統 | 網址 | 使用者 |
|---|---|---|
| 受試者版 | https://sw9526.github.io/College-Student-Research-Scholarship-NSTC/ | 參與研究的大學生 |
| 管理者版 | https://sw9526.github.io/College-Student-Research-Scholarship-NSTC/admin.html | 研究者（需管理密碼） |

## 一、受試者版

### 作答前請準備

- 只能使用**電腦**（桌機或筆電），瀏覽器視窗寬度至少 900px。手機、平板與觸控為主的裝置無法作答。
- 預留約 50–60 分鐘，在安靜、不受打擾的環境獨立完成。
- 作答期間請勿查詢資料、離開作答視窗、重新整理或關閉頁面。

### 作答流程

| 步驟 | 畫面 | 說明 |
|---|---|---|
| 1 | 裝置檢查 | 不是電腦或視窗太窄時，停在說明頁，無法繼續。 |
| 2 | 研究說明與知情同意 | 依計畫書第七節：研究目的、程序與時間、記錄的資料、風險與益處、酬謝、資料保存、自願參與、聯絡方式。勾選同意後繼續。 |
| 3 | 背景問卷 | 預設題目：學測年度（**可複選**）、是否重考、是否看過施測年度的國文試題或解析、是否當過國文家教、國文級距（五標，填最高的一次，可選「不記得了」）、年級、中文是否為母語。題目可在管理者版增刪（見「頁面文字」）。 |
| 4 | 作答說明 | 按下「開始」後畫面切換為全螢幕。說明每個題組建議作答時間（`SET_MINUTES_HINT`）。 |
| 5 | 練習題組 | 熟悉畫重點、完成題組的確認與心力評定。**不計分、不上傳**。 |
| 6 | 正式題組 | **依序作答，完成後不能返回**（見下方）。 |
| 7 | 回饋問卷 | 是否全程獨立作答（不影響酬謝）、作答時間是否足夠、是否曾想回到前面的題組、操作不清楚之處（選填）、其他意見（選填）。 |
| 8 | 完成 | 顯示「作答完成，謝謝你的參與」與酬謝領取表單連結（**非必填**，與作答資料分開保存）。不顯示受試者編碼。 |

### 正式題組的作答方式

- 同一個題組內可以自由作答、改答與畫重點；不確定的題目可以留空。
- 按「**完成這個題組**」會跳出頁面內的確認視窗：「還有 N 題未作答。完成這個題組後就不能再返回，確定要完成嗎？」（全部作答時不提未作答題數）。
- 確認後**立即**評定心力（1 非常非常少 ～ 9 非常非常多），接著進入下一個題組；最後一個題組評完心力後進入回饋問卷。
- **畫重點**：按住滑鼠拖曳選取文章、題幹或表格中的文字，放開後就會標上螢光；「橡皮擦」再拖曳一次即可擦掉；「清除全部畫記」一次清除這個題組的所有螢光。
- **上方圓圈**：每個階段（同意、背景、說明、練習、回饋）與每個題組各一個，只顯示進度，不能點。
- **左上角已用時間**：正式題組的累計作答時間（`SHOW_TIMER` 可關閉），評定心力時暫停，練習不計。
- **退出全螢幕**時，畫面上方出現提示列，按一下即可回到全螢幕。

### 防止資料流失與重複作答

- 作答期間離開或重新整理頁面前，瀏覽器會先提醒。
- **勾選知情同意後就開始保存進度**（瀏覽器的 sessionStorage）。重新整理後會回到原本的地方：
  - 背景問卷：直接回到問卷，已填的答案（含複選題）都還在，不必再看一次知情同意。
  - 作答說明之後：先出現「繼續作答」，回到原本的頁面；題組內已作答的內容與畫記都還在，中斷的這段時間記成一次離開（`via: reload`），不算作答時間。
  - 回饋問卷：已填的答案與文字都還在。
  - `Sessions` 的 `n_reloads` 記錄重新整理次數；重新整理不會產生重複的受試者資料。關閉分頁後 sessionStorage 會清除，無法接續。
- 完成作答後，localStorage 會記下「已完成」；**同一台電腦、同一個瀏覽器**再開啟網址會看到「你已經完成過本研究」。
- **測試模式**（研究團隊自己檢查頁面用）：管理者版「題目編輯」左下角的「測試受試者頁」連結（網址加上 `?test=` 與 `config.js` 的 `TEST_KEY`，可用 `&booklet=B` 指定題本）。測試模式下頁面上方有提示列、不會擋重複作答、完成後也不會記下「已完成」；作答資料會標記為測試（`Sessions` 的 `is_test`），管理者頁預設排除，也不計入題本分派的人數。**不要把測試連結給受試者。**

### 系統會記錄的資料

作答內容、每個題組的作答時間、每題第一次作答的時間與改答紀錄、畫重點的內容與時間點、心力評分、作答期間離開視窗的次數與時間、退出全螢幕次數、重新整理次數、複製或右鍵嘗試次數、背景資料與回饋問卷、裝置資訊（瀏覽器與螢幕尺寸）。系統**不蒐集姓名、學號**等可識別個人的資訊。

**時間怎麼算**：一律是「停留在該題組畫面的累計時間」，心力評定頁與其他頁面的時間不算進去。

| 欄位（試算表 `Responses`） | 意義 |
|---|---|
| `rt_ms` | 題組作答時間（從進入題組到確認完成） |
| `first_rt_ms` | 確認完成、評定心力前的累計時間（依序作答下與 `rt_ms` 相同） |
| `n_visits`、`visits` | 進入這個題組的次數（只有重新整理會增加）；每次的開始時間（從練習結束、正式作答開始起算）、停留時間、結束方式（`done` 確認完成、`reload` 重新整理中斷） |
| `first_answer_ms`、`answer_log`、`highlight_log`、`leaves` 的時間點 | 都是該題組的累計時間，例如 20000 表示在這個題組待了 20 秒時 |
| `save_seq` | 上傳順序編號，用來判斷哪一筆最新 |
| `flags`、`flag_log` | 舊版的「不確定」標記欄位，已停用（保留欄位以免既有資料錯位） |

離開視窗只計算在正式題組畫面時切到其他視窗或分頁，以及重新整理中斷的時間；練習、心力評定與其他頁面都不計算。

**上傳失敗的處理**：每個題組評完心力後上傳一次；完成時再確認所有題組都已送達，失敗的重試一次。仍失敗時，`Sessions` 的 `save_failed` 欄會記下哪些資料沒存到，管理者頁會**預設排除**這位受試者，排除原因為「部分資料未能儲存」。受試者看到的仍是一般的完成畫面。若連完成紀錄都沒存到，這位受試者會顯示為「未完成」，同樣不納入分析。

背景資料的學測年度若複選，`Sessions` 的 `exam_year` 會以「、」連接，例如 `113學年度、114學年度`。預設的背景題目存在 `Sessions` 的同名欄位；管理者新增的題目存在 `bg_extra` 欄（JSON，`{題目代號: 答案}`，複選以「、」連接），受試者 CSV 會把每一題展開成一欄。

## 二、管理者版

開啟管理者網址，輸入管理密碼登入。同一個瀏覽器分頁內重新整理不需要再登入；按右上角「登出」即可清除。

### 題目編輯

1. **左欄｜題組列表**：依題本分組，點選即可編輯。**拖曳題組可以調整順序，也可以拖到其他題本**（順序自動重新編號）。下方「新增題組」「新增題本」（自動使用下一個字母，例如 C），以及測試連結。
2. **中欄｜編輯欄位**
   - **題組代號**：例如 `114-1`，不可重複。
   - **題本**：填 `A` 或 `B`，受試者會被自動分到目前人數較少的題本。填 **`練習`** 的題組是所有人共用的練習題組（不分派、不計分）；沒有設定時使用系統內建的練習題組。
   - **順序**：在左欄拖曳調整；題號依順序自動連續編號。
   - **啟用**：取消勾選後，受試者不會看到這個題組。
   - **來源說明**：只在管理者預覽中顯示（`config.js` 的 `SHOW_SOURCE_NOTE` 為 `false` 時）。
   - **保留換行**：新詩、古詩等需要照原本分行的文章請勾選；沒勾時，從 PDF 貼上的段落內換行會自動合併。
   - **文章**：段落之間空一行，可用以下標記：

     | 標記 | 效果 |
     |---|---|
     | `__文字__` | 畫底線（例如「上文畫線處」）；題幹、選項也可用 |
     | `**文字**` | 粗體 |
     | 段落開頭 `【甲】` | 甲、乙、丙等多文本的標籤；只寫 `【甲】` 一行則標籤單獨成行 |
     | 段落開頭 `注：` | 注釋，以小字顯示 |
     | 每行以 `\|` 開頭 | 表格，例如 `\| 格 \| 格 \|`；格子內容以 `!` 開頭為標題格。表格中的文字也可以畫重點 |
     | 「插入圖片」按鈕 | 上傳圖片（縮到最寬 1200px 存進試算表的 `Images` 工作表），在游標處插入 `![圖說](img:代號)`；圖片內的文字無法畫重點 |

   - **題目**：題幹、(A)–(D) 選項、正確答案、選項排列（自動／一行一個／一行兩個／一行四個）。可用 ↑ ↓ 調整題目順序。
3. **右欄｜即時預覽**：受試者看到的畫面，可直接試畫重點、點選項。預覽窗較窄時會等比例縮小，換行位置與受試者畫面相同。

三欄之間的分隔線可以拖曳調整寬度（「頁面文字」分頁也是），寬度會記在這台電腦；雙擊分隔線恢復預設。登入後，上方的「已連線 Google 試算表」可直接開啟試算表（網址由後端在登入後提供，不寫在公開的程式碼裡）。

編輯完成後按**「儲存全部變更」**，儲存前會自動檢查漏填。儲存後立即生效。

> 施測開始後請盡量不要修改題目；若一定要改，請記下修改時間與內容。正確答案登錯可以直接修正，所有受試者的分數會自動重算。

### 頁面文字

受試者各頁的文字都可以修改並即時預覽：裝置檢查、研究說明與知情同意、背景問卷題目、作答說明、練習題組前後的說明、完成題組的確認視窗、心力評定題目、回饋問卷題目、完成頁、重複作答與接續作答的提示、退出全螢幕的提示列。

- 格式：空一行分段；`# ` 大標題、`## ` 小標題；每行以 `- ` 開頭為條列；`**粗體**`、`__底線__`。
- 變數：`{{YEARS}}`（施測年度，例如 114或115）、`{{SET_MINUTES}}`、`{{N_SETS}}`（題組數）、`{{N}}`（未作答題數，只用在確認視窗）。
- `【待填：…】` 會以醒目底色標示，頁面列表與上方也會提醒。**知情同意的酬謝內容、資料保存期限、研究者與指導教授聯絡方式目前是待填，正式施測前請填好。**
- **背景問卷題目**：在「背景問卷」頁可以新增、刪除、調整順序，修改題目文字、題型（單選、複選、簡答）、選項（一行一個）與是否必答，右側即時預覽。
  - 「學測年度」與「是否看過試題」會用在排除條件，標示為**鎖定**：可以改題目文字，但不能刪除、不能改選項。
  - 「還原預設題目」可回到預設的 7 題。
  - **施測開始後請不要再改題目**，否則前後受試者的資料無法比較。
- 修改後按「儲存頁面文字」；只會存下與預設不同的文字與題目（試算表的 `Texts` 工作表），「還原預設文字」可回到預設。

### 收集資料

- **上方按鈕**：「重新整理」取得最新資料；可下載三種 CSV（試題分析、作答資料、受試者），用 Excel 開啟中文不會亂碼。
- **人數摘要**：已完成、未完成、各題本完成人數、納入分析人數。
- **排除條件**（可勾選、可調整）：
  - 作答期間累計離開視窗超過 N 秒（預設 30 秒，含重新整理中斷的時間）。
  - 測試資料（預設勾選）：用測試連結產生的資料。
  - 學測年度為施測年度（`ITEM_YEARS`，預設勾選）：例如預試時勾選 114 或 115 學年度者。
  - 背景資料表示看過施測年度試題（預設勾選）。
  - 部分資料未能儲存（預設勾選）。
  - 自評未獨立作答（預設不勾選）。
  - 只有「已完成」且未被排除的受試者會納入試題分析；練習題組不分析。
- **試題分析表**：每題的人數、答對率 P、鑑別度 D（依題本總分取前後各 27%，納入人數少於 4 人時不計算；D 小於 .20 以紅字標示）、留空率、各選項選答比例、題組平均心力與平均作答時間。
- **受試者列表**：編碼、題本、狀態、開始時間、得分、作答時間、離開視窗次數與秒數、退出全螢幕次數、複製嘗試次數、是否看過試題、排除原因。被排除者以刪除線顯示。

### 匯出的 CSV

| 檔案 | 每一列 | 用途 |
|---|---|---|
| 試題分析.csv | 一道題目 | 與官方答對率、鑑別度及 AI 模擬結果比對 |
| 作答資料.csv | 一位受試者的一道題目 | 自行計算或做進一步統計（含是否納入分析、作答時間、進入題組次數） |
| 受試者.csv | 一位受試者 | 背景資料（含國文級距、年級、中文母語，以及管理者新增的背景題目，每題一欄）、作答時間、重新整理次數、回饋問卷、排除情形與未能儲存的資料 |

## 三、維護說明（研究者）

| 檔案 | 用途 |
|---|---|
| `index.html` | 受試者版 |
| `admin.html` | 管理者版 |
| `assets/config.js` | 設定：後端網址 `API_URL`、施測年度 `ITEM_YEARS`、最小視窗寬度、每題組建議分鐘數、是否顯示已用時間、酬謝表單網址、是否對受試者顯示來源說明、試題文字大小 |
| `assets/render.js` | 題組版面與標記、頁面文字格式（受試者與預覽共用） |
| `assets/texts.js` | 受試者各頁的預設文字與版型（受試者與「頁面文字」預覽共用） |
| `assets/participant.js`、`assets/admin.js`、`assets/api.js`、`assets/common.css` | 兩個系統的程式與樣式 |
| `apps-script/Code.gs` | Google 試算表後端程式（貼在試算表的 Apps Script 中） |

- **`ITEM_YEARS`**：預試為 `[114, 115]`；正式研究改為 `[115, 116]`。背景問卷的題目、學測年度選項（往前推 5 年）與兩個排除條件都會跟著改。
- **修改 `Code.gs` 後**：在 Apps Script 先執行一次 `setup`（建立新的工作表與標題列，不會動到資料），再「部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署」，網址不變。
- **試算表工作表**：`Sets`（題組）、`Sessions`（一人一列）、`Responses`（每人每題組一列，以 `save_seq` 最新的為準）、`Texts`（修改過的頁面文字）、`Images`（題組圖片）。
- **示範題組**：管理者版「載入示範題組」會載入 6 個自編題組（題本 A、B 各 3 個）與 1 個練習題組。注意：載入後按「儲存全部變更」會**取代**試算表中現有的全部題組。
- **更換管理密碼**：Apps Script「專案設定 → 指令碼屬性」修改 `ADMIN_KEY`，不需重新部署。管理密碼不可寫進任何檔案。
- **正式施測前**：填好知情同意的【待填】內容；刪除試算表 `Sessions`、`Responses` 工作表第 2 列以下的測試資料。
- **測試時重複作答**：完成作答後同一個瀏覽器會被擋下；測試時可改用無痕視窗，或清除該網站的瀏覽資料。
- **字型**：Windows 與 Mac 內建標楷體，顯示與試題本相同；沒有標楷體的電腦會改用「霞鶩文楷」，少數字（如「為」）會顯示為傳統字形。
