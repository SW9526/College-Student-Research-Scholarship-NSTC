# 學測國文閱讀作答研究｜線上施測系統

本系統用於國科會大專生計畫「從認知負荷探討AI模擬作答與人類實際測驗表現落差：以學科能力測驗為例」，由**受試者版**與**管理者版**兩個網頁組成。題目與作答資料都存在研究者的 Google 試算表，本網站與 GitHub 上沒有任何作答資料。

| 系統 | 網址 | 使用者 |
|---|---|---|
| 受試者版 | https://sw9526.github.io/College-Student-Research-Scholarship-NSTC/ | 參與研究的大學生 |
| 管理者版 | https://sw9526.github.io/College-Student-Research-Scholarship-NSTC/admin.html | 研究者（需管理密碼） |

---

## 一、受試者版

### 作答前請準備

- 使用**電腦或平板**，螢幕寬度至少 900px。手機無法作答。
- 預留約 50–60 分鐘，在安靜、不受打擾的環境完成。
- 作答期間請勿查詢資料，也請勿離開作答視窗。

### 作答流程

| 步驟 | 畫面 | 說明 |
|---|---|---|
| 1 | 知情同意 | 閱讀研究說明，勾選同意後繼續。可以隨時關閉網頁退出。 |
| 2 | 背景資料 | 學測年度、是否重考、是否看過114或115學年度國文試題或解析、是否當過國文家教。 |
| 3 | 作答說明 | 按下「開始作答」後畫面切換為全螢幕。 |
| 4 | 題組作答 | 每個題組有一篇文章與數道單選題，版面與學測試題本相同。 |
| 5 | 心力評分 | 每個題組第一次送出後，評定剛才花了多少心力（1 非常非常少 ～ 9 非常非常多）。 |
| 6 | 總覽 | 所有題組都送出後出現，可以回到任何題組檢查或修改答案；按「結束作答」才會交卷，交卷後不能再修改。 |
| 7 | 完成 | 顯示受試者編碼。請等畫面出現「作答完成」再關閉頁面。 |

畫面上方的進度條會顯示目前的填答進度。

### 作答畫面的操作

- **選答**：直接點選項文字，選到的選項會變成淡藍底。改選另一個選項即可改答。
- **畫重點**：按住滑鼠拖曳選取文章或題幹的文字，放開後就會標上螢光。
  - 「橡皮擦」：切換後再拖曳一次，即可擦掉螢光。
  - 「清除全部畫記」：一次清除這個題組的所有螢光。
- **留空**：不確定答案的題目可以不作答，直接按「送出這個題組」。送出按鈕上方會顯示已作答題數。
- **回到前面的題組**：題組送出後，可以用畫面上方的「題組 1、題組 2…」按鈕回到已送出的題組（或目前進行到的題組）。之前的作答與螢光都會保留，改完按「儲存並繼續」會回到目前進行到的題組。按鈕上的 ✓ 表示已送出過；還沒做到的題組不能先跳過去。
  - 心力評分只在題組**第一次**送出時填寫，回來修改不會再問一次。
  - 切換題組**不算**離開作答視窗。

### 系統會記錄的資料

作答內容、每個題組的作答時間、每題第一次作答的時間與改答紀錄、畫重點的內容、心力評分、作答期間離開視窗的次數與時間、退出全螢幕次數、回到各題組的次數與時間，以及背景資料。系統**不蒐集姓名、學號**等可識別個人的資訊。

**時間怎麼算**：一律是「停留在該題組畫面的累計時間」，在其他題組、心力評分頁、總覽頁的時間都不算進去。

| 欄位（試算表 `Responses`） | 意義 |
|---|---|
| `rt_ms` | 題組作答時間：所有進入次數的停留時間總和 |
| `first_rt_ms` | 第一次送出（填心力評分）前的累計時間，與心力評分對應 |
| `n_visits`、`visits` | 進入這個題組的次數；每次的開始時間（從按下「開始作答」起算）、停留時間、離開方式（`submit` 按送出／儲存、`nav` 用題組按鈕切換） |
| `first_answer_ms`、`answer_log`、`highlight_log`、`leaves` 的時間點 | 都是該題組的累計時間，例如 20000 表示在這個題組待了 20 秒時 |

離開視窗只計算在題組畫面時切到其他視窗或分頁；切換題組、心力評分頁、總覽頁都不計算。

## 二、管理者版

開啟管理者網址，輸入管理密碼登入。同一個瀏覽器分頁內重新整理不需要再登入；按右上角「登出」即可清除。

### 題目編輯

畫面分成三欄：

1. **左欄｜題組列表**：依題本（A、B…）分組，點選即可編輯；最下方「新增題組」。
2. **中欄｜編輯欄位**
   - **題組代號**：例如 `114-1`，不可重複。
   - **題本**：填 `A` 或 `B`。受試者會被自動分到目前人數較少的題本。
   - **順序**：同一題本內的出現順序；題號會依順序自動連續編號。
   - **啟用**：取消勾選後，受試者不會看到這個題組。
   - **來源說明**：例如「114學年度學測國文 第21–22題」，只在管理者預覽中顯示。
   - **文章**：段落之間空一行。從 PDF 貼上時，段落內的換行會自動合併。
   - **題目**：題幹、(A)–(D) 選項、正確答案、選項排列（自動／一行一個／一行兩個／一行四個）。可用 ↑ ↓ 調整題目順序。
   - 下方按鈕：「新增題目」「複製此題組」「刪除此題組」（刪除需按兩次確認）。
3. **右欄｜即時預覽**：受試者看到的畫面，可直接試畫重點、點選項。預覽窗較窄時會等比例縮小，換行位置與受試者畫面相同。

編輯完成後按**「儲存全部變更」**。儲存前會自動檢查漏填（題組代號、題本、文章、題幹、選項、正確答案），有缺漏時會列出，不會儲存。儲存後立即生效，下一位開啟受試者網址的人就會看到新版本。

> 施測開始後請盡量不要修改題目；若一定要改，請記下修改時間與內容。正確答案登錯可以直接修正，所有受試者的分數會自動重算。

### 收集資料

- **上方按鈕**：「重新整理」取得最新資料；可下載三種 CSV（試題分析、作答資料、受試者），用 Excel 開啟中文不會亂碼。
- **人數摘要**：已完成、未完成、各題本完成人數、納入分析人數。
- **排除條件**（可勾選、可調整）：
  - 作答期間累計離開視窗超過 N 秒（預設 30 秒）。
  - 背景資料表示看過114或115學年度試題。
  - 只有「已完成」且未被排除的受試者會納入試題分析。
- **試題分析表**：每題的人數、答對率 P、鑑別度 D（依題本總分取前後各 27%，納入人數少於 4 人時不計算；D 小於 .20 以紅字標示）、留空率、各選項選答比例、題組平均心力與平均作答時間。
- **受試者列表**：編碼、題本、狀態、開始時間、得分、作答時間、離開視窗次數與秒數、退出全螢幕次數、複製嘗試次數、是否看過試題、排除原因。被排除者以刪除線顯示。

### 匯出的 CSV

| 檔案 | 每一列 | 用途 |
|---|---|---|
| 試題分析.csv | 一道題目 | 與官方答對率、鑑別度及 AI 模擬結果比對 |
| 作答資料.csv | 一位受試者的一道題目 | 自行計算或做進一步統計（含是否納入分析、累計與首次送出前的作答時間、進入題組次數） |

作答與得分都以受試者**最後交卷時**的答案為準；作答時間為累計時間。
| 受試者.csv | 一位受試者 | 背景資料、作答時間與排除情形 |

## 三、維護說明（研究者）

| 檔案 | 用途 |
|---|---|
| `index.html` | 受試者版 |
| `admin.html` | 管理者版 |
| `assets/config.js` | 設定：後端網址 `API_URL`、最小螢幕寬度、酬謝表單網址、是否對受試者顯示來源說明、試題文字大小 |
| `assets/render.js` | 題組版面（受試者與預覽共用） |
| `assets/participant.js`、`assets/admin.js`、`assets/api.js`、`assets/common.css` | 兩個系統的程式與樣式 |
| `apps-script/Code.gs` | Google 試算表後端程式（貼在試算表的 Apps Script 中） |

- **修改 `Code.gs` 後**：在 Apps Script「部署 → 管理部署作業 → 編輯 → 版本：新版本 → 部署」才會生效，網址不變。若新增了欄位，部署前先執行一次 `setup` 更新標題列（不會動到資料）。
- **`Responses` 每位受試者每個題組只有一列**：受試者回來修改後會覆蓋成最新內容（依 `n_visits` 判斷新舊，網路延遲造成的舊資料不會蓋掉新資料）。
- **更換管理密碼**：Apps Script「專案設定 → 指令碼屬性」修改 `ADMIN_KEY`，不需重新部署。管理密碼不可寫進任何檔案。
- **正式施測前**：刪除試算表 `Sessions`、`Responses` 工作表第 2 列以下的測試資料；若有酬謝領取表單，填入 `config.js` 的 `REWARD_FORM_URL`。
- **字型**：Windows 與 Mac 內建標楷體，顯示與試題本相同；沒有標楷體的電腦會改用「霞鶩文楷」，少數字（如「為」）會顯示為傳統字形。
