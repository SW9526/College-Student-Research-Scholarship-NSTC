# 學測閱讀線上施測系統

國科會大專生計畫「從認知負荷探討AI模擬作答與人類實際測驗表現落差」的線上施測網站。

| 檔案 | 用途 |
|---|---|
| `index.html` | **受試者版**：知情同意 → 背景問卷 → 題組作答（可畫重點）→ 每題組後的心力耗費量表 |
| `admin.html` | **管理者版**：新增／編輯題目（右側即時預覽受試者畫面）、查看收集到的資料與試題分析、下載 CSV |
| `assets/config.js` | **唯一需要修改的設定檔**（後端網址等） |
| `apps-script/Code.gs` | 貼到 Google 試算表的後端程式（不用上傳到 GitHub 也可以） |

---

## 先試用（示範模式）

`config.js` 的 `API_URL` 留空時是示範模式，題目與作答資料只存在這台電腦的瀏覽器。

1. 用瀏覽器打開 `index.html`，完整作答一次。
2. 打開 `admin.html`，密碼輸入 `demo`，就能看到剛才的資料，也能試著編輯題目。

---

## 正式上線（約 20 分鐘）

### 一、建立 Google 試算表後端

1. 用**師大 Google 帳號**建立新的試算表，例如命名為「國科會施測資料」。
2. 上方選單「擴充功能 → Apps Script」，刪掉預設內容，貼上 `apps-script/Code.gs` 的全部內容，按儲存。
3. 編輯器上方的函式選單選 `setup`，按「執行」並授權。
   - 出現「Google 尚未驗證這個應用程式」是正常的（因為是你自己的程式），點「進階 → 前往（不安全）」即可。
   - 執行完後，試算表會多出 `Sets`、`Sessions`、`Responses` 三個工作表。
4. 左側齒輪「專案設定」→ 最下方「指令碼屬性」→ 新增屬性 `ADMIN_KEY`，值是你自訂的**管理密碼**（不要用常用密碼）。
5. 右上「部署 → 新增部署作業」→ 類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。

### 二、設定網站

6. 打開 `assets/config.js`：
   - `API_URL` 貼上剛才的網址。
   - 正式施測時把 `SHOW_SOURCE_NOTE` 改成 `false`（不顯示題目來源）。
   - 如果有酬謝領取表單，把網址填進 `REWARD_FORM_URL`。

### 三、上傳到 GitHub 並開啟 Pages

7. 到 repo 頁面 → 「Add file → Upload files」，把 `index.html`、`admin.html`、`README.md` 和整個 `assets` 資料夾拖進去 → 「Commit changes」。
8. repo 的「Settings → Pages」→ Source 選「Deploy from a branch」→ Branch 選 `main`、資料夾 `/(root)` → Save。約 1–2 分鐘後就能使用：
   - 受試者：`https://sw9526.github.io/College-Student-Research-Scholarship-NSTC/`
   - 管理者：`https://sw9526.github.io/College-Student-Research-Scholarship-NSTC/admin.html`

### 四、輸入題目並測試

9. 打開管理者頁，用 `ADMIN_KEY` 登入 →「新增題組」（或先按「載入示範題組」看格式）。
   - **題組代號**：例如 `114-1`、`115-3`，不能重複。
   - **題本**：填 `A` 或 `B`；受試者會被平均分派到其中一個題本。
   - **順序**：同一題本內的出現順序。
   - **文章**：段落之間空一行；從 PDF 貼上時，段落內的換行會自動合併。
   - 右側就是受試者看到的畫面，可以直接試畫重點。確認無誤後按「儲存全部變更」。
10. 用受試者網址自己完整做一次，到管理者頁「收集資料」確認資料有進來。
11. **正式施測前**，到試算表把 `Sessions` 和 `Responses` 的測試資料（第 2 列以下）刪掉。

## 注意事項

- **資料在哪裡**：所有作答資料只存在你的 Google 試算表；網站與 GitHub repo 裡沒有任何作答資料。
- **repo 是公開的**：任何人都能看到網站程式與 `admin.html` 頁面，但沒有 `ADMIN_KEY` 就無法看資料或改題目。**不要把 ADMIN_KEY 寫進任何檔案。**
- **正確答案不會傳給受試者**：受試者頁只拿得到題目與選項，計分在管理者頁進行。如果發現答案登錯，在管理者頁修正後分數會自動重算。
- **施測開始後盡量不要改題目**：修改會立即生效。若一定要改，請記下修改時間與內容。
- **修改 `Code.gs` 後**要到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」，修改才會生效；網址不會變。
- **試題版面**：仿照學測國綜試題本（單欄、標楷體＋Times New Roman、「X-Y為題組」加底線、文章整段縮排、題號凸排）。題號依題本內順序自動編號。選項排列預設依長度自動排成一行四個／兩個／一個，也可在每題的「選項排列」手動指定。文字大小在 `config.js` 的 `EXAM_FONT_PX` 調整，其他尺寸會等比例縮放。
- **字型**：Windows 與 Mac 內建標楷體，會與試題本相同；少數沒有標楷體的電腦會改用「霞鶩文楷」，字形相近，但少數字（如「為」）會顯示為傳統字形。
- **排除條件**：管理者頁可勾選「作答期間累計離開超過 N 秒」與「看過試題」，只有已完成且未被排除的受試者會納入試題分析。

## 每位受試者記錄的資料

- **Sessions**（一人一列）：題本、開始／完成時間、總時間、背景問卷、複製或右鍵嘗試次數、裝置資訊。
- **Responses**（每人每題組一列）：作答、留空題數、題組作答時間、每題首次作答時間、改答紀錄、畫記內容與時間點、心力耗費（1–9）、作答期間離開視窗的次數與秒數、退出全螢幕次數。
